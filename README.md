# Portfolio Website

Vignesh M's creative portfolio for video editing, motion graphics, AI videos, and graphic design.

[View the live portfolio](https://vignesh-m-creative-portfolio.netlify.app/)

## Run locally

This is a static HTML, CSS, and JavaScript website. No build or package installation is required.

From this folder, run `python -m http.server 8000`, then open http://localhost:8000.

## Files and media

The website code and referenced SVG files were recovered from the public Netlify deployment on November 13, 2026. This is a snapshot of the deployed frontend; original development history and Netlify account configuration are not included.

Images, videos, the resume PDF, and remaining media assets load from the existing Netlify site. Their paths have been converted to absolute URLs so they continue working when this code runs locally or on another host. The site requires internet access and that Netlify deployment to remain available. `media-dependencies.json` lists these references, including a platform-icon path generated at runtime.

The existing Netlify deployment has not been changed or connected to this repository for automatic deployment.
